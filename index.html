Pro Battle Arena 已建立 GitHub 倉庫。
因完整遊戲檔約 450KB（含 1000+ 陀螺資料），請用以下方式完成上線：

  1. 開啟倉庫：csfclayton/beyblade-x-arena
  2. 點 Add file → Upload files
  3. 上傳遊戲的 index.html（覆蓋現有檔）
  4. Settings → Pages → Source 選 Deploy from a branch → Branch: main / root
  5. 數分鐘後開啟：csfclayton.github.io/beyblade-x-arena

圖片請與 HTML 放同一資料夾，檔名對應名稱括號內代號，例如 (BL-EVE-077428-01) → BL-EVE-077428-01.png
