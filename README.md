# BEYBLADE X // Pro Battle Arena

瀏覽器版 2D 俯視角爆旋陀螺對戰遊戲。

## 線上遊玩

https://csfclayton.github.io/beyblade-x-arena/

## 檔案說明

| 檔案 | 說明 |
|------|------|
| `index.html` | 主遊戲 |
| `mild.mp3` | 輕度撞擊音效 |
| `mid.mp3` | 中度撞擊音效 |
| `strong.mp3` | 重度／必殺撞擊音效 |

請將音效檔與 `index.html` 放在同一目錄。

## 操作

- 拖曳發射
- 空白鍵發動必殺
- CSV 匯入／匯出、還原預設
