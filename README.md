# BEYBLADE X // Pro Battle Arena

瀏覽器版 2D 俯視角爆旋陀螺對戰遊戲。

## 線上遊玩

啟用 GitHub Pages 後開啟：

`https://csfclayton.github.io/beyblade-x-arena/`

## 功能

- 陀螺對戰物理、屬性相克（攻擊 / 防禦 / 持久）
- 多場地特效（經典、加速、黑洞、冰面）
- 必殺技 Cut-in、自動必殺
- 自訂陀螺、圖片上傳
- CSV 匯入／匯出（支援 UTF-8 / UTF-16 / Big5）
- 圖片依名稱括號自動對應同資料夾檔名

## 本機使用

1. 下載 `index.html`
2. 將陀螺圖片放在同一資料夾
3. 用瀏覽器開啟 `index.html`

## 操作

- 拖曳發射
- 空白鍵發動必殺技
- 右上角可匯出／匯入 CSV、還原預設
